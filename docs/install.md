# Установка

## Требования

| Компонент | Значение |
| --- | --- |
| Nursultan | клиент со скриптингом, API 2 и выше (текущая версия 9) |
| MCP в клиенте | Scripts → MCP → Enabled |
| Python | 3.10+ для запуска `.py` или сборки; конечным пользователям нужен только `.exe` |
| Windows | основная платформа; мост работает и на других ОС, где запущен клиент |

## Шаг 1. Включить MCP

Клиент → вкладка **Scripts** → кнопка **MCP** в шапке → отметить **Enabled**. Кнопка **Copy link** копирует ссылку вида:

```
http://127.0.0.1:<порт>/mcp/<токен>
```

Порт и токен сохраняются между запусками. Токен — единственная креда доступа: не публикуйте ссылку.

## Шаг 2. Настроить bridge.json

В репозитории лежит шаблон `bridge/bridge.example.json`. Скопируй его в `bridge/bridge.json` рядом с мостом и вставь ссылку из шага 1. Файл `bridge.json` в git не отслеживается — с секретами в репозиторий он не попадает.

| Ключ | По умолчанию | Назначение |
| --- | --- | --- |
| `proto` | `1` | версия протокола, менять только вместе с обновлением кита |
| `mcpLink` | `""` | ссылка из шага 1; пустая — мост не стартует |
| `pollMs` | `150` | период опроса скриптов, мс; меньше 100 не опускать |
| `allowlist` | `[]` | разрешённые хосты; пусто — разрешены все (с логированием) |
| `allowPrivate` | `false` | разрешить запросы в локальные сети и на `127.0.0.1` |
| `maxTimeoutSec` | `60` | потолок таймаута запроса |
| `maxBodyBytes` | `8388608` | потолок тела ответа, 8 МиБ |
| `secrets` | `{}` | ключи API: имя → значение, подставляются как `{{KEY}}` |
| `requestLog` | `requests.log` | журнал всех запросов |
| `stateFile` | `bridge-state.json` | состояние дедупликации |
| `cleanAfterHours` | `24` | возраст файлов ответов, после которого они удаляются |

Минимальная настройка:

```json
{
  "mcpLink": "http://127.0.0.1:1234/mcp/ВАШ_ТОКЕН"
}
```

Секреты для примеров:

```json
{
  "secrets": {
    "gemini": "ВАШ_GOOGLE_AI_KEY",
    "telegram": "123456789:AA..."
  }
}
```

## Шаг 3. Запустить мост

```
python bridge/nursultan_bridge.py
```

или собранный exe (см. ниже):

```
nursultan-internet-bridge.exe
```

Консоль печатает `мост запущен` и каждый запрос:

```
req id=1 script=Погода GET wttr.in -> 200 312ms 15B
```

## Шаг 4. Проверить

```
python bridge/nursultan_bridge.py --check
```

или:

```
powershell -ExecutionPolicy Bypass -File doctor.ps1
```

Проверка подтверждает: конфиг читается, MCP отвечает, список скриптов получен, папка assets доступна на запись.

## Сборка exe

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

Скрипт ставит PyInstaller и собирает `dist/nursultan-internet-bridge.exe`. Конфиг ищется рядом с exe, поэтому `bridge.json` кладётся в ту же папку.

## Автозапуск

Ярлык `nursultan-internet-bridge.exe` в папку:

```
shell:startup
```

Мост не требует прав администратора и не трогает реестр сам.

## Обновление

Заменить `nursultan_bridge.py` или exe, сохранить `bridge.json`. При смене `proto` мост напечатает предупреждение в лог.
