# Решение проблем

## Мост

| Симптом | Причина | Действие |
| --- | --- | --- |
| `mcpLink пуст` | ссылка не вставлена | Scripts → MCP → Enabled → Copy link → в `bridge.json` |
| `MCP недоступен` каждые 30 с | клиент не запущен или MCP выключен | включить MCP, проверить ссылку через `--check` |
| `--check` падает с `MCP: ...` | токен сменился | скопировать ссылку заново, обновить `bridge.json` |
| запрос в логе не появляется | скрипт не писал в слот | проверить, что скрипт включён и отправляет запрос |
| `отклонён: хост ... не входит в allowlist` | allowlist задан и хост не в нём | добавить хост в `allowlist` или очистить список |
| `отклонён: хост ... ведёт на приватную сеть` | запрос в локальную сеть | `"allowPrivate": true`, только если это действительно нужно |
| `{{KEY}} в запросе, но keyref отсутствует` | в URL есть `{{KEY}}`, директивы нет | добавить `keyref: имя` в запрос |
| `keyref ... не найден` | имени нет в `secrets` | добавить `"имя": "значение"` в bridge.json |
| `тело больше N байт` | ответ крупнее `maxBodyBytes` | поднять лимит или сузить запрос через API |
| журнал пустой, консоль работает | лог-файл недоступен | проверить права на папку с мостом |

## Скрипт

| Симптом | Причина | Действие |
| --- | --- | --- |
| `references blocked symbol` | в скрипте запрещённый пакет | убрать `java.net`/`java.io`/`Thread`, вернуться к `internet-core` |
| скрипт не загрузился с ошибкой компиляции | синтаксис или API | свериться с оригинальной документацией |
| ответа нет, потом `timeout` | мост не запущен | запустить мост, проверить `--check` |
| ответа нет, ошибок нет | `netTick()` не вызывается | добавить вызов в каждый тик |
| ответ прочитан дважды | не сбрасывается `netReady` | `netReady = false` сразу после чтения |
| `netSend` возвращает `-1` | предыдущий запрос ещё в полёте | ждать `netBusy() == false` |
| `netCode = 0`, тело `bridge error: jsonpath ...` | путь не найден или ответ не JSON | исправить `jsonpath`, проверить ответ через журнал |
| `netCode = 0`, тело `truncated response` | файл дописывался в момент чтения | не повторять чтение того же номера, ответ перезапишется |
| статус 200, а данные пустые | API вернул пустое поле | проверить `jsonpath` и документацию стороннего API |
| `bridge error: конверт: ...` | нарушён формат запроса | отправлять запрос только через функции `internet-core` |

## Установка скрипта

| Симптом | Причина | Действие |
| --- | --- | --- |
| скрипта нет в списке | файл не в `%APPDATA%\Nursultan\scripts` | переместить, дождаться перекомпиляции |
| карточка красная | ошибка компиляции | прочитать сообщение в Scripts-табе |
| настройки не видны | `net.req` скрыт `visibleWhen { false }` | это ожидаемо, слот нужен только мосту |
| `requireApi(2)` валит загрузку | старый клиент | обновить клиент |

## Диагностика

```
python bridge/nursultan_bridge.py --check
python bridge/nursultan_bridge.py --selftest
powershell -ExecutionPolicy Bypass -File doctor.ps1
```

`--selftest` проверяет разбор конверта, jsonpath, allowlist и запись ответа без сети и без клиента.

Журнал запросов — `requests.log` рядом с мостом: там каждый запрос с хостом, статусом, временем и размером.

## Лимиты, о которых часто забывают

| Лимит | Значение |
| --- | --- |
| обработчик | 250 мс |
| файл ответа | 8 МиБ |
| символов в значении настройки | 65536 |
| ключей в конфиге скрипта | 4096 |
| запросов в полёте | 1 на скрипт |
| минимальный `pollMs` | не ниже 100 |
