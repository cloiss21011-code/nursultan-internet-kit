# Что это

**Nursultan Internet Kit** — официальное дополнение к [документации скриптов Nursultan](https://docs.nursultan.fun/), которое даёт скриптам доступ в интернет.

Песочница скриптов запрещает `java.net` — сокеты и HTTP внутри `.kts` невозможны. Кит решает это снаружи: отдельный процесс **мост** ходит в сеть за скрипт, сам скрипт продолжает работать только через разрешённые API (`assets` и свои настройки). Ни один запрещённый символ в скрипт не добавляется, загрузка проходит стандартную проверку клиента.

## Состав

| Файл | Что это |
| --- | --- |
| `bridge/nursultan_bridge.py` | мост: опрашивает скрипты через MCP, выполняет HTTPS, кладёт ответы в assets |
| `bridge/bridge.json` | конфиг моста: ссылка MCP, allowlist, ключи API, лимиты |
| `templates/net-core.kts` | блок `internet-core` — вставляется в каждый сетевой скрипт целиком |
| `templates/example-*.kts` | готовые скрипты: погода, POST/JSON, Gemini, Telegram |
| `docs/` | этот сайт |
| `doctor.ps1` | проверка установки |

## Как устроено

```
скрипт (.kts)                мост (bridge)                интернет
netSend(...)                 
  → слот net.req      →      читает по MCP         →     HTTPS-запрос
  ← assets.text(...)  ←      пишет .env файл       ←     ответ
```

1. Скрипт пишет запрос в собственный вход `net.req` — это разрешённый API настроек.
2. Мост читает слот через MCP-сервер клиента (`127.0.0.1`, включается в Scripts-табе).
3. Мост выполняет запрос: allowlist, запрет приватных сетей, `{{KEY}}` подставляет секрет из `bridge.json`.
4. Ответ атомарно пишется в `scripts/assets/_net/resp/<id>/net-<номер>-<nonce>.env`.
5. Скрипт читает файл в тике через `assets.text` и работает с текстом.

Каждый шаг использует только официальные механизмы клиента: настройки скрипта, MCP, чтение assets. Подробный разбор цикла моста, формата конверта и jsonpath — [Внутреннее устройство](architecture.md).

## Что можно делать

- погода, курсы, статусы серверов, патчноуты — регулярные GET;
- любые REST API — POST с JSON и заголовками;
- языковые модели — Gemini, DeepSeek, OpenRouter и любые совместимые endpoint'ы;
- Telegram-боты по `getUpdates` и `sendMessage`, Discord-вебхуки;
- свои сервисы: парсинг страниц, базы знаний, онлайн-таблицы.

## Честные ограничения

| Ограничение | Причина |
| --- | --- |
| только исходящие соединения | мост — HTTP-клиент, входящие вебхуки и серверы невозможны |
| нет стриминга | ответ приходит целиком, частей нет |
| латентность от 1,5 с | тик 50 мс + опрос моста 150 мс + сам запрос |
| нет парсера JSON в скрипте | песочница; JSON разбирает мост по директиве `jsonpath` |
| один запрос в полёте | один слот `net.req` на скрипт |
| нет блокирующего ожидания | обработчик ограничен 250 мс, ожидание — в тиках |
